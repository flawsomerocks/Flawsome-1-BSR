Setup steps (sirf ek baar)

Aapke sheet ka purana Apps Script code touch nahi hoga. Naya code alag project mein jayega.

  1. Naya tab kholo: script.google.com, New project dabao. Jo code likha ho wo sab delete karke, neeche wala code paste karo aur Ctrl+S dabao.
  2. Upar right mein Deploy > New deployment. Type: Web app. Execute as: Me. Who has access: Anyone. Deploy dabao, Allow karo (agar "unsafe" dikhe to Advanced > Go to project). Phir Web app URL copy karo.
  3. Wo URL neeche box mein paste karke Save & sync dabao. Sheet mein naye tab bante dikhenge: Invoice Log, Invoice Items Log, Month Wise Revenue, History Report, aur Blinkit row bhar jayegi.
  4. Bas. Script khud MIS as per RO tab mein Channel Wise Revenue Split ke neeche Blinkit row dhundh ke months bharti hai. Purane numbers "MIS Backup Log" tab mein save rehte hain.
